Chaotic Japan Adventure Points Game — Interactive Web Version
Welcome to the interactive version of the Chaotic Japan Adventure Points Game! This web app lets you enter player names, update scores for various fun categories, and automatically calculates total points and the trip champion.

Features
Editable player names for up to 4 players

Score inputs for main categories (3 points for winner, 1 point for runner-up)

Daily mini chaos challenges with checkbox scoring (1 point each)

Automatic total points calculation per player

Displays the current trip champion or indicates a tie

Mobile-friendly layout for easy use on phones and tablets

How to Use
Open the index.html file in any modern web browser.

Enter player names in the input fields.

Input scores for each category or check mini challenge boxes.

Totals and champion update automatically as you enter data.

Hosting
